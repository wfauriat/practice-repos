# MI-T100 Industrial Temperature Sensor — Datasheet

## Overview

The MI-T100 is Meridian Instruments' entry-level industrial temperature sensor, designed for continuous monitoring in manufacturing, warehousing, and HVAC environments. Launched in 2013, it remains the company's best-selling product with over 120,000 units deployed worldwide.

## Specifications

| Parameter | Value |
|-----------|-------|
| Measurement range | -40°C to +125°C |
| Accuracy | ±0.5°C (at 25°C) |
| Resolution | 0.1°C |
| Response time | 8 seconds (in still air), 2 seconds (in flowing liquid) |
| Sensing element | Platinum RTD (PT1000) |
| Operating voltage | 3.3V to 5.5V DC |
| Power consumption | 45 mW (active), 8 µW (sleep) |
| Communication | MeridianLink (RS-485 physical layer) |
| Sampling rate | Configurable: 1 sample/sec to 1 sample/hour |
| Data logging | Internal 512 KB flash (up to 65,000 readings) |
| Dimensions | 78mm × 32mm × 22mm |
| Weight | 48g (without cable) |
| Ingress protection | IP67 |
| Housing material | 316L stainless steel |
| Cable length | 2m standard (custom lengths: 0.5m, 5m, 10m, 25m) |
| Operating humidity | 0–95% RH (non-condensing) |
| MTBF | 150,000 hours |

## Variants

- **MI-T100-S**: Standard probe (straight, 100mm insertion length)
- **MI-T100-L**: Long probe (straight, 250mm insertion length)
- **MI-T100-A**: Angled probe (90°, 100mm insertion length)
- **MI-T100-W**: Waterproof variant rated to IP68 (submersible to 3m for 72 hours)

## Calibration

Factory calibrated with NIST-traceable certificate. Recommended recalibration interval: 12 months. Field recalibration is supported via MeridianLink using a 2-point calibration method (ice point + boiling point).

## Ordering Information

Part numbers follow the format: MI-T100-{variant}-{cable length}-{voltage}. Example: MI-T100-S-2M-5V for a standard probe with 2m cable at 5V.
