# craft/ide/

Editor power-use practice. Currently scoped to **VS Code on Linux** (default keymap).

If you ever want to mirror this for another editor, the structure is:

- `keybindings.md` — the ~20 shortcuts to know cold + drill prompts to practice them.
- `snippets/` — sample user snippets organised by language.
- `workflows.md` — end-to-end: rename across project, extract function, run nearest test, debug a failing test, etc.
- `extensions.md` — must-have extensions with one-line "why" each.

## See

- [`vscode/keybindings.md`](./vscode/keybindings.md) — the 20-shortcut drill list.
- [`vscode/workflows.md`](./vscode/workflows.md) — the workflows to internalize.
- [`vscode/extensions.md`](./vscode/extensions.md) — recommended extensions.
- [`vscode/snippets/`](./vscode/snippets/) — copy these into your `~/.config/Code/User/snippets/` to enable them.
